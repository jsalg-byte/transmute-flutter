# Project guide for contributors and coding agents

This is the Flutter client for Transmute. Production is the Flutter web app at
`https://transmute.mzootfb.xyz`; it uses a separate Expo/Fastify service at
`https://api.transmute.mzootfb.xyz`. The API and its migrations live in the
sibling `transmute-mobile` repository (checked out locally at
`/Users/mzootfb/Sites/transmute-mobile` on the primary development machine).

## Where work belongs

| Work | Source of truth |
| --- | --- |
| Screens and interactions | `lib/features/<feature>/presentation/` |
| Shared UI, theme, and responsive shell | `lib/shared/` |
| Domain models/calculations/contracts | `lib/core/domain/` |
| API payload mapping | `lib/core/api/api_repositories.dart` |
| In-memory demo behavior | `lib/core/data/mock_repositories.dart` |
| Repository selection and shared state | `lib/core/providers.dart` |
| Fastify routes, SQL, and production schema | sibling repo `transmute-mobile/api/` |
| Deployed Flutter web UI | checked-in `release/web/`, generated by `scripts/build_web_release.sh` |

New features normally add/extend a domain repository interface, implement
both API and mock adapters, register them in Riverpod, then connect the screen.
Do not call Dio from widgets or add speculative wire-field aliases.

## High-value checks

From this repo, use the pinned SDK:

```sh
.fvm/flutter_sdk/bin/flutter analyze
.fvm/flutter_sdk/bin/flutter test
./scripts/build_web_release.sh
```

Widget tests may need permission to bind a local socket. A sandbox socket error
occurs before assertions run. The user owns browser verification; report static
checks and deployment/container checks separately from visual QA.

For API changes, inspect the exact migration and current production schema
before applying SQL. Coolify does not run API migrations automatically. For a
release with both server and UI changes, apply/verify the migration, deploy the
API, then deploy the rebuilt Flutter bundle. Do not include unrelated dirty
files from the sibling checkout in a scoped commit.
